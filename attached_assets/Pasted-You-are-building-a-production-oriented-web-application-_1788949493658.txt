ROLES
Implement enum Role:

SUPER_ADMIN
CITY_ADMIN
MAHALLI_ADMIN
SECTOR_ADMIN
MUSYRIF

Role meaning:
- SUPER_ADMIN: global access.
- CITY_ADMIN: access limited to one city.
- MAHALLI_ADMIN: access limited to one mahalli.
- SECTOR_ADMIN: access limited to one sector.
- MUSYRIF: access only to assigned groups.

CORE BUSINESS RULES
Backend authorization is mandatory. Do not rely only on frontend hiding buttons.

Important rules:
1. City contains Mahalli.
2. Mahalli contains Sector.
3. Sector contains Group.
4. Group cannot exist without Sector.
5. Musyrif can manage multiple groups.
6. One group can have maximum one active Musyrif.
7. Musyrif cannot create groups.
8. Musyrif cannot assign themselves to a group.
9. Musyrif cannot assign another Musyrif.
10. Group can exist without Musyrif.
11. Soft delete is the default.
12. Important admin actions must create ActivityLog.
13. Permission is role + scope, not role alone.

Flow:
1. Find group.
2. Check current user permission.
3. Check target user exists.
4. Check target user role is MUSYRIF.
5. Check target user is active.
6. Find old Musyrif assignment for the group.
7. Remove old assignment if exists.
8. Create new UserGroup assignment.
9. Create GroupAssignmentHistory.
10. Create ActivityLog.
11. Use Prisma transaction.

One group must not have more than one active Musyrif.
